# tinyOS：FAT12 软盘操作系统学习路径图

目标：在 QEMU 中启动自己编写的系统，通过命令行创建、查看和修改自己构造的 FAT12 软盘镜像；提交说明实现原理的技术报告。图形界面属于进阶目标。

## 实现路线

当前内核运行在 16 位实模式，通过 BIOS 中断输出文本；下一步实现命令行和软盘扇区读写。开发初期使用两张虚拟软盘：A 盘启动系统，B 盘作为 FAT12 数据盘。

## 阶段与验收

| 阶段 | 学习重点 | 自己实现 | 验收标准 |
| --- | --- | --- | --- |
| 0. 明确架构 | BIOS、启动盘、数据盘、内核、扇区之间的关系 | 画出“按键 → 命令 → FAT12 → 扇区 → 镜像”的调用路线 | 能解释一次 `dir` 如何读取磁盘 |
| 1. 命令行 | 键盘输入、退格、输入缓冲区、命令解析 | 提示符、`help` 和未知命令提示 | 可连续输入命令，系统不死机 |
| 2. 扇区读写 | 512 字节扇区、磁盘编号、BIOS 读写接口及错误处理 | `read_sector`、`write_sector` | 测试盘的数据写入后，重启仍可读回 |
| 3. 自制 FAT12 盘 | 引导扇区/BPB、两份 FAT、根目录、数据区 | 从空白 1.44 MB 镜像构造 FAT12 数据盘 | 系统和独立 FAT 工具均能识别 |
| 4. 只读 FAT12 | 8.3 文件名、目录项、簇链、12 位 FAT 表项 | `dir`、`type NAME.TXT` | 能列出文件并读出跨簇文件 |
| 5. 文件写入 | 空闲簇分配、两份 FAT 更新、目录项写入与删除 | `write NAME.TXT 内容`、`del NAME.TXT` | 写入、重启、读取和删除结果正确 |
| 6. 目录与格式化 | 子目录、`.`/`..`、元数据初始化 | `mkdir NAME`、`format` | 能创建目录；格式化测试盘后仍可正常使用 |
| 7. 交付 | 边界测试、报告与演示 | 技术报告、演讲材料、可复现的演示流程 | 他人能复现并理解实现 |
| 8. 进阶 GUI | 宿主机界面与系统内界面的区别 | 根据课程要求选择实现路线 | 图形操作作用于同一张 FAT12 镜像 |

## 命令范围与实现顺序

计划实现六个文件系统命令：`format`、`dir`、`type`、`mkdir`、`write`、`del`；`help` 作为辅助命令，不计入“至少五个”。实现顺序为先读、后写、最后格式化，避免过早进行破坏性操作。`format` 初期只针对 QEMU 中的测试数据盘，并要求确认；不针对宿主机物理设备。
